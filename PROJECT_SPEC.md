ЦЕЛЬ ПРОЕКТА
HJKsell — персональное Windows-приложение для учёта закупки и перепродажи одежды.

Основной источник закупок — польский Vinted.

Валюта покупки:

PLN

Валюта учёта и продажи:

BYN

Основной принцип работы:

Купил → отправил фото + сумму PLN в Telegram → HJKsell получил вещь → продал → ввёл BYN → HJKsell самостоятельно сделал все расчёты

Приложение заменяет существующую Google-таблицу, сохраняя привычный вертикальный принцип отображения вещей, но значительно улучшая интерфейс, статистику и автоматизацию.

ОГРАНИЧЕНИЯ V1
V1 полностью локальная.

При этом архитектура должна позволять в будущем создать V2 с сервером и read-only доступом друга.

СЕБЕСТОИМОСТЬ
Формула:

Себестоимость BYN = PLN × курс вещи

Например:

150 × 0.85 = 127.50 BYN

ПРИБЫЛЬ ВЕЩИ
Прибыль = Продажа BYN − Себестоимость BYN

Например:

300 − 127.50 = +172.50 BYN

X
X = Продажа / Себестоимость

Пример:

300 / 127.50 = 2.35x

ROI
ROI = Прибыль / Себестоимость × 100%

Пример:

172.50 / 127.50 × 100 = +135.29%

Важно:

1x = 0% ROI

2x = 100% ROI

3x = 200% ROI

СУММА ПРОДАЖ МЕСЯЦА
Считается по sale_date.

То есть:

Σ sale_price

всех товаров, фактически проданных в выбранном месяце.

Неважно, когда они были куплены.

КОЛИЧЕСТВО ПРОДАЖ МЕСЯЦА
Аналогично:

количество вещей с sale_date внутри выбранного месяца.

СРЕДНИЙ X МЕСЯЦА
Берутся вещи, проданные в этом месяце.

Средний X = сумма X / количество продаж

Непроданные не участвуют.

ROI МЕСЯЦА
Не брать простое среднее individual ROI.

Используется:

ROI = Σ прибыль проданных вещей / Σ себестоимость этих проданных вещей × 100%

Это финансово корректнее.

РАСХОДЫ И ROI
Основной товарный ROI должен оставаться рассчитанным по товарам.

Дополнительно в аналитике можно показать:

ROI после расходов

Формула:

(реализованная прибыль − расходы) / себестоимость проданных товаров × 100%

Чтобы пользователь видел оба показателя.

Не переносится.

Это заметно упрощает V1.

РЕЗЕРВНОЕ КОПИРОВАНИЕ
Сложная backup-система в V1 не является приоритетом.

Однако SQLite-файл должен физически находиться отдельно от .exe.

Обновление или переустановка HJKsell не должны автоматически удалять пользовательскую БД и папку фотографий.
